# Machine Learning Lab 2026

Semester 5 machine learning laboratory work. The repository contains Jupyter notebooks, supporting datasets, and practical exercises covering Python foundations, data analysis, regression, and classification.

## Lab Contents

| Lab | Topics | Main files |
| --- | --- | --- |
| 1 | Descriptive statistics implemented in Python: mean, median, mode, variance, and standard deviation | [lab 1 ML.ipynb](Lab%201/lab%201%20ML.ipynb) |
| 2 | NumPy arrays, arithmetic, aggregation, empty and filled arrays, random values, dot products, sorting, and string operations | [lab 2 ML.ipynb](Lab%202/lab%202%20ML.ipynb) |
| 3 | Pandas data loading and inspection with Matplotlib visualizations using the Iris dataset | [lab 3 ML.ipynb](Lab%203/lab%203%20ML.ipynb), [Iris.csv](Lab%203/Iris.csv), [iris_dataset.csv](Lab%203/iris_dataset.csv) |
| 4 | USA house-price prediction and regression analysis | [lab4.ipynb](Lab%204/lab4.ipynb), [USA_Housing - USA_Housing.csv](Lab%204/USA_Housing%20-%20USA_Housing.csv) |
| 5 | Binary Iris classification with logistic regression and evaluation metrics including accuracy, error rate, Cohen's kappa, precision, recall, F1 score, and a confusion matrix | [Lab5ML.ipynb](Lab%205/Lab5ML.ipynb), [iris_data.csv](Lab%205/iris_data.csv) |
| 6 | Support Vector Machine classification with linear, polynomial, and Gaussian RBF kernels, including accuracy, hinge loss, and decision boundaries | [lab.ipynb](Lab%206/lab.ipynb), [iris_dataset_SVM - iris_dataset_SVM.csv](Lab%206/iris_dataset_SVM%20-%20iris_dataset_SVM.csv) |
| 7 | Multi-class Iris classification with `MLPClassifier`, different hidden-layer configurations, and classification reports | [lab.ipynb](Lab%207/lab.ipynb), [iris_dataset_MLP - iris_dataset_MLP.csv](Lab%207/iris_dataset_MLP%20-%20iris_dataset_MLP.csv) |
| 8 | Gaussian discriminant analysis with Linear Discriminant Analysis (LDA), Quadratic Discriminant Analysis (QDA), and class-distribution plots | [lab8.ipynb](Lab%208/lab8.ipynb), [iris_dataset_GDA - iris_dataset_GDA.csv](Lab%208/iris_dataset_GDA%20-%20iris_dataset_GDA.csv) |
| 9 | Iris classification with Gaussian Naive Bayes, training and testing accuracy, and a classification report | [lab9.ipynb](Lab%209/lab9.ipynb), [iris_dataset_NB.csv](Lab%209/iris_dataset_NB.csv) |

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- scikit-learn

Install the common dependencies with:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Open a notebook from its lab folder so that relative dataset paths resolve correctly.
